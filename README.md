AI Blog Writer Drafts is an AI-powered WordPress plugin that automatically generates complete blog posts using OpenAI. It uses your existing WordPress content, categories, tags, site information, and custom prompts to create relevant articles tailored to your website.

The plugin can generate full blog posts, featured images, SEO meta titles and descriptions, automatically assign existing categories and tags, and perform a second AI review pass to improve structure and content quality before publishing.

Posts can be generated manually as drafts or automatically created and published on a configurable schedule using WordPress WP-Cron.

Ideal for WordPress websites looking to automate AI content generation, blogging, SEO content creation, and scheduled publishing with OpenAI.
